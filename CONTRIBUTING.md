# Contributing to ArtiTrack

## Before Making Changes
- Review the existing project structure.
- Understand the purpose of the files you plan to modify.
- Avoid unrelated changes.

## Before Committing
- Review changes using `git status`.
- Check changes using `git diff`.
- Run relevant tests when applicable.

## Commit Guidelines
- Use clear, descriptive commit messages.
- Keep each commit focused on one task.
- Explain the purpose of documentation changes.
