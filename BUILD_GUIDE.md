# ArtiTrack Build Guide

## Prerequisites
- Install a C compiler supporting C11.
- Install a C++ compiler supporting C++17.
- Ensure the required build tools are available.

## Build
Run `make` in a supported terminal.

## Run
Execute `./artitrack` after a successful build.

## Tests
Run `make test` to execute the project's test suite.

## Cleanup
Run `make clean` to remove generated build files.
