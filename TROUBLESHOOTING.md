# ArtiTrack Troubleshooting

## Build Issues
- Check that the required C and C++ compilers are installed.
- Verify that build tools are available in the terminal.
- Review the build instructions in README.md.

## Test Issues
- Run the documented test command.
- Read the error output to identify the cause.
- Report test failures honestly.

## Git Issues
- Run `git status` to review local changes.
- Check the current repository before committing.
- Review changes before pushing to GitHub.
